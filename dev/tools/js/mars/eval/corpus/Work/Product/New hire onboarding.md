# New hire onboarding checklist

## Before the first day

- [ ] Laptop ordered and shipped to the home address.
- [ ] Accounts created: email, chat, code hosting, and the ticket tracker.
- [ ] A buddy assigned from the same team.
- [ ] Contract, tax forms, and bank details collected by HR.

## First week

- Meet the manager on day one and agree on goals for the first 30 days.
- Set up the development environment with the setup script; ask the buddy when it fails.
- Ship one small change to production by Friday, even a typo fix.
- Join the team rituals: standup, planning, and the Friday demo.

## First month

- Shadow two on-call shifts before joining the rotation.
- Read the architecture overview and the last three incident reviews.
- A 30-day check-in with the manager: what is confusing, what is missing.
