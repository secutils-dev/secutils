# Welcome

This library holds sample notes for testing search. Each note is fictional: the people,
places, and numbers are made up.

## How the notes are organized

- **Personal**: home life, pets, food, travel, and health.
- **Work**: engineering designs, runbooks, security policies, and product plans.
- **Notes**: things being learned, training plans, and loose ideas.
- **Shared with me**: notes that friends and colleagues sent over.
- **Archive**: notes kept for reference only.
