    Privacy

    Your documents stay in your browser. MARS stores documents, folders, and review threads in this browser's IndexedDB storage. They are never sent to the Secutils.dev server in readable form. Clearing site data for this page deletes them, so use Export all for backups.

    Short links. When you copy a short link, your browser encrypts the document and Secutils.dev stores only the encrypted copy, for the period you choose (1, 7, or 14 days). The decryption key exists only in the link, so the server can't read the document. Only the browser that created a link can delete it early. Your IP address is kept for one hour to rate-limit link creation.

    Full links. A full link carries the whole document in the URL fragment (#…), which browsers never transmit to the server.

    Loading from a URL. When you use ?url= or the "Load URL" box, your browser fetches that address directly; the Markdown is never relayed through the Secutils.dev server.

    Smart search (optional, off by default). When you turn it on, your browser downloads the model you pick from Hugging Face, and the search library from jsDelivr, once; the browser caches them. Documents are indexed and searched inside this browser, and the index stays in its storage. Nothing about your documents or searches is sent anywhere.

    Map basemaps. GeoJSON and TopoJSON viewers fetch map tiles directly from OpenStreetMap. Tile requests reveal the displayed geographic area. Your Markdown source is not included.

    Anonymous usage analytics. We use Plausible Analytics, a privacy-first, GDPR-compliant tool, to collect aggregate usage data. No cookies, no personal data, no individual tracking. Full details in the Plausible Data Policy.

    See the full Secutils.dev privacy policy for details on the wider service.

    Credits

    MARS is powered by the following open-source libraries:

    • marked - Markdown parser and compiler, used to render the source into HTML.
    • highlight.js - syntax highlighter, used to colourise fenced code blocks.
    • KaTeX - math typesetting, used to render $…$ and $$…$$ formulas.
    • Mermaid - diagram renderer, used to turn ```mermaid code blocks into inline SVG diagrams.
    • topojson-client - converts TopoJSON objects into GeoJSON for map display.
    • CodeMirror - extensible code editor, powers the source editing mode.
    • fflate - builds and reads .zip exports, and extracts 3MF packages in a worker (MIT).
    • saxes - parses namespace-aware 3MF XML in a worker (ISC).
    • Transformers.js - runs the optional smart-search embedding models in the browser (Apache-2.0), with GTE Small (MIT) or EmbeddingGemma 2 (Apache-2.0).
    • EUI - Elastic UI design language; MARS borrows its icons and color tokens.
