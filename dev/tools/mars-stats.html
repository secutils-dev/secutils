Privacy & data

Owner-only statistics. The dashboard token grants read access to aggregate telemetry only. The token stays in this tab's session storage. The private link carries it in a URL fragment, which the page removes after opening. API requests send it in an Authorization header.

Server-side credentials. MARS, this dashboard, and its sampling tracker can access the selected MARS_STATS_API_KEY secret. The account API key never appears in the page, exports, or history. Request tracking is disabled for this dashboard.

Bounded history. A scheduled API tracker collects one snapshot every thirty minutes, even when this page is closed. Snapshots expire after thirty days. History contains counts, sizes, quotas, and timestamps, not documents, keys, link contents, or visitor identities.

No analytics. This private dashboard runs no analytics and no third-party JavaScript. Fonts load from Google Fonts.
